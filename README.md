## Tecnologías utilizadas

- **Lenguaje:** Java 21
- **Build Tool:** Maven
- **Testing:** JUnit 5
- **IDE:** VS Code

---

## Cómo ejecutar el proyecto

### Maven:

```bash
# Compilar el package del proyecto:
  mvn clean package
# Ejecutar tests:
  mvn test
# Ejecutar el JAR:
  java -jar target/ExamenRecuDAM-1.0-SNAPSHOT.jar
```
